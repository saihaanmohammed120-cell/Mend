# Coordinator integration handoff

## Part 1 — boundaries and dependency mapping

Inputs are the inherited v1.2 TRD and design brief, App Flow, Stage 5 schema, and the six scoped module contracts. The existing Site is externally versioned and stays intact. Coordinator ownership includes application assembly, dedicated worker entry points, disk fixture persistence, local rehearsal, genuine HTTP integration fixtures, final regression output and the delivery archive. No provider account or deployment credential was available.

## Part 2 — implementation

`mend.bootstrap` composes explicit test adapters or real provider adapters. Live release cannot be unlocked with an environment toggle while the trusted report controller and measured safety gates remain unresolved. The API uses real Supabase identity even in local_test mode; the credential-free rehearsal is a separate CLI. Immutable disk artifacts support shared test service volumes, and local artifact URIs remain plainly non-downloadable. `mend.worker` separates scheduling from deadline enforcement. The TypeScript browser bridge preserves the existing interface and owns session/CSRF, replay and cleanup without changing brand tokens.

## Part 3 — review and verification

Cross-module review fixed lease-blocked deadline cancellation, SQL/Python evidence differences, duplicate fixing transitions, read-only reconciliation, immutable artifact recovery, malformed-response usage accounting, semantic diagnostic hashing and resource cleanup. Coordinator review also aligned the prompt limit, retained public actual usage and command evidence, fixed receipt SSE floating-point serialization, and enforced exact frozen command arguments in the service as well as SQL. Runtime resource cleanup is idempotent and attempts every owned close.

Full final output is in `docs/verification`. The local rehearsal never executes candidate source. Framework and PostgreSQL fixtures explicitly skip when prerequisites are absent. Compilation cannot substitute for those runtime checks. Docker, CI, real account inference and remote termination are unverified until actually run.

## Part 4 — convergence and limitations

The archive contains complete module functions, MIT license, deployment preparation, an operator-gated measurement spike, scoped four-part handoffs and runnable regressions. The static Site is not republished or connected to a pretend backend. The current model identifier is an account-level candidate, not evidence of a successful inference request. Job native timeout has a 3600-second floor; sending cancel at 60 seconds does not establish termination by 60. Trusted external report generation, provider isolation and the strict stop bound remain production blockers. Process-local fixture jobs also do not establish restart recovery across real processes. Public repository publication and judge access have not been performed.
