# Mend delivery — 29 October 2026

Mend's local review now accepts source-map JSON files without flattening folder paths. The backend assembly forwards the configured inference-reservation cap, and offline CI verifies the production dependency lock before testing. These changes preserve the existing Paper and Proof interface and both release holds. No hosted database change or live Nebius discovery, inference, job or cancellation experiment was performed.

## Behavior delivered

- `/tools`: original, candidate and receipt-source maps can be imported from local JSON files. Relative nested Python paths, Unicode and source BOM/CRLF text are retained. Limits are 20 files, 200,000 UTF-8 source bytes, and 3,000,000 JSON transport bytes. Existing strict JSON, duplicate-key, source-path and Unicode validation runs before replacement; invalid input preserves previous text and invalidates the affected review. The guide documents this interface.
- Pending local reads are independent by input. Same-input replacement, manual editing, captured loads, Clear and unmount suppress stale reads. Compare/inspect waits for pending input reads. Every accepted read retires affected comparison/receipt evidence. Input failures identify their target and survive an unrelated read's success until that target is corrected or cleared. No upload, browser persistence or code execution was added.
- `MEND_TASK_COST_CAP` is validated as an optional positive finite value and passed from `Settings` to each assembled `TaskService`. Missing/blank remains unconfigured; nonfixture inference fails closed without a cap. The existing reservation gate rejects an over-budget next call before recording usage/generating output. This retains floating-point inference accounting, not a Cloud/runner/account spending limit. No price, currency, credential or actual spending authorization was invented. See [budget contract](../backend/docs/TASK_BUDGET_CONFIGURATION.md).
- The backend full/HTTP job and real Next-to-backend fixture chain install the unchanged hashed `requirements.runtime.lock`, constrain test-extra resolution to all locked versions, run `pip check`, then verify every installed runtime pin. The verifier rejects malformed, unpinned, unhashed, duplicate and empty locks. This closes the earlier gap where CI resolved a different FastAPI/Starlette set. Production dependency versions were not upgraded.
