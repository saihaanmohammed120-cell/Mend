## Description ready for factual editing

### Inspiration

Reviewing an AI repair requires more than a passing badge: a developer needs the source, unchanged protected checks, the result and an honest account of where the evidence came from. Mend makes those identities and limits inspectable.

### What currently works

The Paper and Proof frontend reviews one Python module with proposed protected checks, preserves exact text, invalidates stale reviews and exports input without execution. A backend/CLI prepares an unapproved frozen contract. The evidence interface distinguishes simulated playback from captured local checks and unsigned provenance. Backend source includes secure sessions, owner-scoped tasks, bounded orchestration, evidence validation and immutable artifact handling. Database and provider holds remain enforced.

### Technology and verification

Next.js/React frontend and Python/FastAPI backend, with Supabase adapters and a gated Nebius Token Factory/AI Cloud architecture. The exact-commit CI covers backend HTTP, production frontend/browser checks, a real Next/Uvicorn transport chain with fixture identity, image builds and a disposable PostgreSQL rollback fixture. Public source preserves MIT licensing. Those checks do not certify real provider execution, signing authority or stop timing.
